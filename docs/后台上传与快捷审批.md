# 后台上传与快捷审批（2026-10-26）

## 后台上传

整理窗口点击确认后立即关闭并显示上传队列，可继续上传其它大类或切换站内页面。各批次固定申请人、学年、大类、附件及小项归属，最多两批并行；每个小项的全部附件保存成功后，才确认该小项并安排OCR。

队列显示小项和文件处理阶段；文件传输及服务器解析未结束时不会宣称完成。失败保留未完成文件，可重试或放弃，重试复用已有小项及成功附件。确认响应丢失时先核对服务器是否已确认，避免重复操作。完成后增量更新列表，不切换用户所在页面、不关闭后来打开的弹窗、不重建已打开的表单或原件。

尚未发送完毕的文件保存在当前浏览器窗口，站内导航不会中断；刷新或关闭窗口会有标准离开提醒，继续传输需要保留窗口。已确认上传的OCR、AI任务由服务器继续执行。

队列按账号隔离。换账号时清理旧的业务界面快照，旧上传和迟到的轮询、401响应不会改写新账号的状态。学年固定传给服务端，管理员切换统计学年后，旧排队材料不会被静默归入新学年。

## 快捷审批

对照区及完整详情直接提供绿色“批准”和红色“驳回”。批准立即提交审核操作，不弹确认窗口；驳回才打开理由表单，原因必须主动选择，备注可选，不再选择一遍审核结果。

辅导员驳回保留“本次不改变活动资格／认定有效／认定无效”的选项。批准按既有后端规则处理活动资格。已通过小项只向有权限的辅导员显示红色驳回入口。

所有操作继续检查权限、审核阶段、禁止自审、内容版本和幂等标识；同一小项处理时锁住重复点击，同一请求重试复用标识。迟到结果不会跳回旧条目或关闭新弹窗。主列表保留材料比对入口，审批按钮位于具体条目的核对区。
