# 评分依据与本项目计算规则

- 基准70；不做扣分。集体活动上限3，思想政治理论学习3，社会服务4，学术科研及创新创业10，文体竞赛6，学生组织社团任职4，奖励5。总分理论105，十进制两位四舍五入。
- 集体活动：普通每次0.3，两次广场舞同一文件一条0.6；突出贡献经人工认定可满3。
- 理论学习：各级党团组织理论学习培训每次1，省、部级每次2，优秀学员另加1；年累计封顶3。
- 社会服务：志愿服务每学年32小时及以上1分，未满按比例，不能每32小时重复加1；年度志愿子项封顶1。校级社会实践合格团队成员1；市、县见习及挂职1；省级及以上挂职或国际组织实习2；先进个人及团队另加1，社会服务总封顶4。AI建议按工时给出，最终申报分由学生确认、人工审核，汇总执行子项及大类上限。
- 科研及创新创业：国家/高水平国际一二三等奖10/9/8；省级8/6/4；校、地方政府、部门、企事业、学会一二三及优秀奖4/3/2/1；特等奖按一等奖。是否同一竞赛重复申报由审查员判断；系统将审核通过的小项分值累加后封顶10，不自动按项目取最高。
- 论文：学校认定国际期刊学生一/二/三/四及后作者10/8/6/2；国内核心或国际会议6/5/4/1；国内一般期刊或国内会议3/2/1。第一署名单位须西安交通大学。
- 专著一/二/三作者10/8/6，之后每后移一位减1，参编1。专利原文指向i/ii类，自动建议按原件交人工核定；不套用专著递减表。国际、国内学术会议上入围优秀论文另加1，科研总上限10。
- 文体：国际/国家文艺一二三及优秀6/5/4/3，省级4/3.5/3/2，校级2/1.5/1；体育国际/国家前三6/5/4，第4—8名3，省级前三4/3.5/3，第4—8名2，校级前三2/1.5/1，第4—8名0.5；破省级及以上纪录5，破校纪录3。重复竞赛交审查员判断，审核通过的小项分值累加后封顶6，不自动按项目取最高。少见特殊情况可写备注，不设置破纪录级别等额外表单。
- 任职：兼任多项仅取最高。满一年优秀/良好/合格：高层职务4/3.5/3，中层副职3.5/3/2.5，支委、组织中层正职、团支书或班长2/1.5/1，学生组织干事、一般班干部、舍长1/0.75/0.5；不合格0。不满一年按工作时间人工核定且不超过对应满年分，上限4。
- 奖励：军警民共建和先进荣誉，或道德风尚、救人、拾金不昧等受表彰，全国/省/市/校/院5/4/3/2/1；为学校赢得声誉的突出好人好事1，多事可累加；总上限5。

学生可修改AI建议及申报分值；固定标准有争议由人工审核，系统不静默回滚到AI建议。单项和批量提交本身确认当前分值，包括0；不设置独立确认分值按钮或重复提交确认。分类封顶、志愿年度子项封顶、任职取最高仍是统一汇总约束。

七类表单统一为具体活动与条目名称、申报分值、备注；只有科研、文体竞赛、任职增加一个自由填写的“获奖/评定等级”和可搜索的“匹配已认定活动”。次数、赛事级别、作者顺序、岗位、任期、工时等计分事实仍从材料提取并保存在分析依据中，不暴露为额外输入框。

科研、文体竞赛、任职的活动资格按活动、大类、学年统一判断。明确有效可复用认定，未知或历史具体范围冲突交辅导员；无效认定须更正匹配。其余四类不因旧隐藏活动匹配阻塞提交。候选包含有效、无效及待认定状态，以内容接近程度匹配，不因有效状态优先选择较远的活动。

竞赛重复判断全部交人工，取消自动替代、拒绝、恢复和按竞赛项目分组取最高；同学生、学年、大类内相同原文件的哈希防重复保留。已有冻结轮次及旧替代记录作为历史保存，不自动重新演算或恢复。

自动建议仍分别识别赛事级别与奖项等第，按政策表计算；本人奖次/考评必须关联本人记录。科研立项/结项、未满年任职、无明确本人结果和政策未列固定分的情形保留现稿并人工核对。逐项原文核对见[政策计分核对](政策计分核对.md)，当前自动计分与提交验收见[七大类验收](七大类自动计分验收.md)。
