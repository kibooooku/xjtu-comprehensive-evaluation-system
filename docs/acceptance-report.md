## 自动化验收

命令：`python -m pytest -q`，最终 **34项通过**；另外新建独立`.venv`、从固定依赖安装后再次运行，同样34项通过。测试使用真实临时SQLite及虚构材料，不使用云额度。

- `test_workflow.py`：11项，计分、审核路由、资格、替代恢复、幂等、状态冲突及范围。
- `test_http_workflow.py`：5项，真实cookie/CSRF/Origin、越权与历史只读，两审查员并发、公示与提交并发。
- `test_organization_history.py`：3项，恶意矩阵作用域不能越班、新学年转班保留历史已通过分、已有申请学年禁止静默转班。
- `test_security_organization.py`：7项，密码会话失效、学号隐私、至少两审查员、管理员无材料权、CSV整批回滚、空ID、班长不可通过矩阵变审查员。
- `test_materials.py`：8项，文件签名/范围、原件访问、公示脱敏失败封闭、迟到AI、预算/缓存、Excel、冻结历史截图、显式应用及改分标记。

`node --check app/static/app.js` 通过。测试框架有一条Starlette建议未来迁移httpx2的弃用提示，不影响当前测试结果。

## 设计细化与交付边界

- 资格适用范围更具体者优先，同等具体度冲突交辅导员。
- 大类属于稳定申请，跨大类在正确入口重新填报；内容与计分自由修改。
- 班级归属按学年留存，不按活动日期硬判断学年。已有申请的学年不允许静默重新归属。
- 恢复只撤销替代造成的状态，不覆盖后续独立人工决定。
- 公示截图在无可靠文字OCR时不返回私图，显示未就绪；学生仍可手填、手动截图并正常进入人工审核。未使用OCR成功不能视为自动脱敏成功。
- 首版是本地完整演示，未部署公网；默认只监听127.0.0.1。
