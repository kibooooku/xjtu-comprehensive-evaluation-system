## 当前交付行为

| 关注点 | 当前行为 |
| --- | --- |
| 按大类整理 | 每学生/学年/大类一份申报，每个主文件默认一个小项，可补多份附件。整理窗口不识别；确认立即回列表并后台持续上传，可继续上传其它类。单文件200MB、PDF500页上限保留。 |
| 自动识别流程 | 先本地检测文字层，再按既有腾讯免费OCR策略补充。材料处理完成自动衔接AI；每用户OCR文件并发最多3、AI小项并发最多3，独立队列，超出排队。站内切页、刷新不取消，一键分析不终止OCR。 |
| 简化表单 | 所有七类仅名称、申报分值、备注。仅科研、文体竞赛、任职追加一个获奖/评定等级和可搜索的已认定活动；不再增加级别、届次、赛道、组别、作品、工时、岗位或破纪录等输入框。自动计分依据仍保留。 |
| 活动搜索 | 检索全库名称、别名和材料关键词，再取最相关候选，不先截断前300条。显示有效、无效、待认定；不因有效状态优先于更近的无效活动，可手动更换或清除。 |
| 资格一致性 | 搜索、详情、提交、审批均按活动、大类、学年判断。历史具体范围冲突或没有可复用通用认定时交辅导员；隐藏的旧范围不改变结果。其它四类不因隐藏旧活动ID阻塞提交。 |
| 直接提交 | 单项和批量点击即确认当前分值，包括0；未保存内容先保存并使用新版本。没有额外提交确认弹窗、同赛事关联选择或独立确认分值按钮。部分失败保留草稿与勾选。 |
| 人工比对 | 同类全部小项在表格对照，审查员判断竞赛重复，绿色批准直接完成、红色驳回填写理由。通过项锁定，待审先撤回，驳回项可改删，大类可继续增补。 |
| 汇总 | 取消自动竞赛替代、拒绝、恢复和项目取最高。科研、文体已通过分值累加后大类封顶；任职取最高及志愿年度子项封顶保留，原文件哈希防重复保留。 |
| 证据与历史 | 本人参与和有效性证据在原件之前；身份与结果能同框则一张，否则最多两张，原页整宽、四分之一页高并标页码。有效性只取完整活动名称、时间、印章。“完整版本与历史”及旧单文件页入口移除，冻结快照和审核记录仍保留。 |
| 原校标准 | 学生、学生审查员、辅导员顶部可新标签页查看原校PDF，接口 `/api/reference/scoring-standard` 受登录保护。 |
| 学年与权限 | 管理员指定当前学年，学生只读显示；旧年材料只读，旧待审仍按权限审核。RBAC、禁止自审、管理员不得读取学生业务材料、公示提交锁继续生效。 |

匹配旁说明为：**匹配已认定活动，便无需辅导员审批活动有效性**。页面同时显示实际认定状态；复用有效认定不免除个人材料及计分审查。

## 保留的既有功能与历史记录

材料流程继续先检查文字层；有可用文字层可直接提取全文及坐标，长扫描件仅首页末页自动识别有效性信息，中间本人信息手动框选。每份文件只检查首页末页印章，多章取最后一个；腾讯免费资源不足或本地保护触发时停止后续云调用，保留结果，不自动切换火山。停止原因区分本地计数、云资源包、限流、鉴权和网络，不能将本地计数当作腾讯余额。

公示脱敏未就绪继续封闭，不回退私图。冻结材料、审核轮次、旧替代记录和历史成绩不自动重写；旧记录不会触发新的替代或恢复动作。升级前备份仍在本地 `instance/backups/`，用户原始证明、运行数据和凭据不提交仓库。

此前的真实接口小样是历史记录，不是本轮自动验收的新调用：腾讯高精度OCR及印章各一次、DeepSeek一次，虚构广场舞2次得到0.60，原图1200×900生成1200×225参与截图。归档见[原结构化结果](real-provider-smoke.json)、[虚构参与图](screenshots/participation-context.png)。
