| 识别入口和布局顺序 | 我的申报为主要上传页，点击大类整理全部文件；材料及识别按钮在左，信息与审核在右；顶部和每大类提供一键分析。 |
| 按大类集中申报 | 每学生/学年/大类一份外层申报。每主文件默认一小项，可给某项补传多附件；弹窗仅本地整理，确认后才上传及入OCR队列。完全相同文件同类去重，跨类允许，疑似重复提示。 |
| 识别跨页继续 | OCR/AI任务持久化，确认后服务端处理，切菜单、刷新、重新登录不取消；任务状态及进度全站可见。相同请求复用任务，成功OCR按图像hash缓存。 |

| AI活动名具体 | 提示词、结果校验均要求具体名称并有OCR线索；首次新稿自动填表。人工稿仅建议，过期结果不覆盖，删项不复原。旧AI建议也能查看，不要求重新调用接口。 |
| 学年统一 | 管理员指定/创建统计学年，学生填报只读显示。旧资料可读、旧待审可审；修改旧年需切回。兼任审查员的学生在审核页可单独筛历史学年。 |

- 腾讯高精度OCR一次（带单字坐标）、印章识别一次；AI复用OCR缓存。

## 框选翻页与单项提交（2026-10-26）

框选弹窗增加同一附件内的上一页、下一页及当前页/总页数，首页末页禁用越界操作。各页的截图、红框、遮挡和证据类型暂存在当前窗口，切回可继续编辑；保存只保存当前页并保持弹窗打开，提示其余待保存页数，关闭会保护未保存草稿。只读用户可翻页查看，不能编辑。快速翻页时迟到的图片不会覆盖当前页。

对照核对区保留独立保存按钮，增加“提交此小项”。未保存修改先保存，再确认提交当前小项，携带保存后的版本，复用原有权限、公示、材料和奖项替代校验；其它已勾选小项保持原状。已批准、待审、历史及无提交权限的内容不展示该按钮。提交失败显示原因并保留内容。
