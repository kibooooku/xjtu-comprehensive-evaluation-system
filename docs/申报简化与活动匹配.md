# 申报简化与活动匹配

当前合同：2026-10-26。本文同步本轮用户确认的简化要求及随后补充的双队列并发、上传后自动分析要求。早期原始grill记录保留历史；涉及竞赛自动去重、替代和重复确认的旧规定由本文更新。

## 填写内容

所有小项保留具体活动与条目名称、申报分值、备注。只有科研、文体竞赛、任职额外显示一个“获奖/评定等级”输入和可搜索的“匹配已认定活动”。

等级统一保存在 `payload_json.result_label`，可以填写“省赛一等奖”“国赛二等奖”“考评良好”等实际结果。名称应包含具体活动，不能只填“集体活动证明”。特殊事项写备注，不再设置届次、赛道、组别、作品、赛事级别、破纪录、岗位、工时或作者顺序等单独输入框。

自动计分需要的赛事级别、奖次、次数、岗位、任期、作者排序、工时等事实仍从原件提取并保存在后端分析依据中。表单精简不改变本人关联和政策计算，保存采用合并更新，不删除未展示的历史字段。其它四类不因旧隐藏活动ID或资格阻塞提交。

## 上传、识别和分析

1. 点击大类入口整理文件，每个主文件默认一个小项，可以为该小项补充附件。此窗口不运行OCR。
2. 确认上传后立即回列表，后台持续上传，用户可以继续整理其它大类。上传上限仍为单文件200MB、PDF500页。
3. 上传确认后先处理已有文字层；可用文字层直接提供文字及原页坐标，扫描页按既有腾讯免费OCR策略处理。材料处理完成自动衔接该小项的AI分析，不要求学生再点一键分析。
4. 每名用户同时最多处理3份OCR文件，同时最多分析3个AI小项。OCR按文件、AI按小项分别排队，两个队列独立，超出上限等待；AI等待本项前置材料，不取消未完成OCR。
5. 后台任务在站内切页和普通刷新时继续；退出登录、关闭最后一个本站标签或失联时暂停，明确继续后恢复，显示识别、排队、分析及耗时提示。空白新稿可自动填表，已手工编辑稿仅保留建议；旧结果不重复运行，迟到结果不覆盖改稿。

一键分析保留为处理未分析项、补充材料或人工重试的入口。它不打断已有OCR。独立并发队列不扩大云预算：仍只使用腾讯免费额度，额度不足或本地保护触发时停止后续云请求，保留已完成结果，不自动购买或切换火山。

本人参与和有效性证据放在原件之前。本人身份与奖次/考评能同框则一张，否则最多两张参与图，均为原页整宽、四分之一页高，并标注来源页码和红框。有效性仅取一处完整活动名称、活动时间、印章；印章仍只查每份文件首页和末页，多章取最后一个，未找到提示人工寻找。长扫描件和文字层策略见[专门说明](文字层与免费OCR策略.md)。

## 匹配已认定活动

组件支持按规范名称、别名搜索，显示规范名称及有效、无效、待认定状态，允许清除或手动更正。旁边固定提示：

> 匹配已认定活动，便无需辅导员审批活动有效性

该提示对应复用当前有效认定。个人材料、本人结果、申报分值仍由审查员审核；待认定和无效候选同时显示实际状态。

搜索遍历当前大类、学年下的可用活动库后排序分页，不再只向AI提供前300条。中文名称、标点、空格和所有有效别名均可参与检索。非空查询按内容相似度排序，不能因为某活动有效就替代更接近的无效活动；空查询提供稳定分页浏览。

AI接收最相关候选及其状态、适用范围，只能选择合法候选ID。唯一明确全名或别名可作匹配兜底；无关材料、普通近似或多个明确目标不能强配。错误ID及错误数据类型被忽略；已停用活动不能被自动重新应用。材料只有合法别名而模型使用规范名称时，应保留可对应的具体名称，不能因此让整次分析失败。

资格在搜索、详情、提交和审批中统一按**活动、大类、学年**判断。优先采用当前学年的通用认定；没有通用认定，或通用与历史具体范围认定相冲突时，返回 `UNKNOWN` 交辅导员确认。旧届次、赛道、组别不作为隐藏条件改变当前表单结果。

| 当前认定 | 提交与审核行为 |
| --- | --- |
| VALID | 可复用活动有效性；学生初审通过后可直接通过 |
| UNKNOWN | 可提交，学生初审后交辅导员认定活动有效性 |
| INVALID | 提示更正匹配，不能将无效活动作为有效认定提交 |

旧学年、跨类及停用匹配可只读显示原名称和ID，不静默改成其它活动。其它四类不展示匹配，也不因旧匹配阻塞；其历史数据保留。

## 提交与审批

单项“提交此小项”和批量“提交选中项”直接执行，没有重复确认弹窗、同赛事关联选择或独立确认分值按钮。提交本身表示学生确认当前填写，包括0分；自动分值待核定时仍展示简短原因，但不再增加额外确认动作。

有未保存修改时，先保存，再用保存后的版本提交。普通保存确认当前填写分值；没有修改时可直接提交已加载的当前稿。单项携带 `expected_version`，批量携带逐项版本；过期返回409并保留输入。批量逐项执行，允许部分成功，失败项保留草稿和勾选；连续点击不能重复提交。

原有权限、当前学年、公示锁、至少一个原文件及基础数字格式检查继续执行。学生审查员和辅导员在同类完整表格里比对所有小项：绿色批准直接完成，红色驳回才填写理由。已通过小项不可修改，待审先撤回，驳回可改删，大类可增补新项。

“完整版本与历史”和旧单份文件页面入口移除，对照核对统一在大类页展示；处理记录、已冻结快照和后台审核历史仍保留。

## 重复判断与汇总

是否同一竞赛、是否重复加分由审查员比对证明并判断。系统取消竞赛项目自动关联、替代、拒绝、恢复及项目取最高；新高奖不改变旧申请，撤回或驳回不恢复其它申请。旧替代记录仅保留为历史，不触发新业务动作。

| 约束 | 当前规则 |
| --- | --- |
| 科研已通过分 | 小项分值SUM，按科研大类10分封顶 |
| 文体已通过分 | 小项分值SUM，按文体大类6分封顶 |
| 任职兼任 | MAX取最高，任职大类4分封顶 |
| 志愿服务 | 年度志愿子项累计封顶1分，社会服务总封顶4分 |
| 其余分类上限 | 继续按当前规则对已通过小项封顶 |
| 完全相同原文件 | 同学生、学年、大类按哈希防重复；改名无效，跨大类可复用 |

学生申报分经人工审核后进入汇总。取消竞赛语义去重不取消原文件防重复，也不取消任职及志愿年度上限。

## 参考PDF与接口

学生、学生审查员和辅导员工作区顶部提供“查看评分标准”，在新标签页打开原校评分PDF：`GET /api/reference/scoring-standard`。接口受登录保护，参考文件与学生私有证明分开。

- `GET /api/activities/search?q=&year_id=&category_id=&limit=20&offset=0` 返回 `{items,total,limit,offset,query}`，支持全库检索和分页。
- `GET /api/activity-matches/{id}?year_id=&category_id=` 读取当前或历史选中值的活动元数据。
- 活动DTO提供规范名、别名、认定状态、适用范围、匹配分及 `EXACT_NAME|EXACT_ALIAS|RELATED` 标记，不公开私有证明。
- 原有单项、批量提交及后台任务API保留；完整字段见[接口合同](v2-interface-contract.md)。RBAC、禁止自审和私有材料保护继续生效。
