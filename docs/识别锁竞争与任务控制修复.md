# 识别锁竞争、暂停与账号删除修复

实现基线：2e3abc3。蓝桥杯视觉设计的文字/印章识别已经成功，AI异常与另外两条材料处理异常的共同根因是数据库长写事务竞争：长PDF证据定位单次约25秒，在写锁内重复计算使其他任务超过30秒等待；调度线程也曾因数据库繁忙退出。

修复将整份证据定位、裁图、AI文字和候选整理移至写锁外，短事务落库时重核来源、内容指纹及任务所有权。调度器遇临时繁忙会退避；任务保存明确数据库来源和不含密钥的诊断。腾讯及同一任务的AI成功HTTP响应先保留私有恢复副本，写回失败后可复用。

所有腾讯文字和印章请求共用JPEG预处理，限制编码、base64、请求体和边长，返回坐标还原至原页；原件不改。实测一张2480×3508渲染页由7.17MB变为3.13MB，分辨率保持。该压缩是通用调用入口，不是对单份历史记录打补丁。

上传、OCR、AI可暂停/继续。站内切页继续，登出由前后端共同暂停；关闭最后一个本站标签暂停，45秒失联兜底。已发请求结果保留后停止后续请求。普通刷新有短时文档标识保护，手动和登出暂停不会被心跳解除。本地尚未上传的文件在关闭页面后需重新选择，服务器已保存进度保留。

进度窗顶部箭头统一收起整个面板，轮询不会重新撑开。管理员用户列表和学生编辑窗新增删除入口：备份后清理本人业务，保留OCR月汇总、共享活动及他人审计引用；必要时匿名保留DELETED占位并释放原用户名和学号。班级职务须先交接，在途任务先暂停再删除。

验证：Windows完整后端582项通过；原83项浏览器回归通过，新增暂停8项、管理员删除8项均通过。离线回归使用虚构材料和服务替身，实际部署用量单独记在本地维护记录中，不与测试混写。
